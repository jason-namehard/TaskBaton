# TaskBaton 0.5.0 — 2026-11-18

TaskBaton（原 Agent Relay）0.5.0 是交接层方向的第一个大版本：验收方可选任意已登记 Agent、首轮提示词、协议层与 `handoff verify/lint`、用户可见改名，以及更严格的迟到回执与探针清理边界。

## 主要变化

- **任意验收方**：验收方下拉可选任意已登记 Agent；首次验收新建任务专用会话，后续复验续接同一会话；验收会话与工作会话分用途保存，不覆盖原会话。
- **首轮提示词**：原“工作要求”改为启动任务用的首轮提示词；验收标准支持手动填写或由发起方按规范格式生成。
- **连接图只读**：不再暂停单个 Agent 方向；旧方向记录保留但不再阻断任务。
- **探针清理**：只清理当前 Agent、当前页面选中的探针；结果显示 Agent、probe、session 和保留原因。
- **规则部署**：支持复制部署提示词交给 Agent 自行确认指令文件，或手动选择指令文件；复制后显示待部署状态和顶部非阻塞提示。
- **协议层**：新增 `AgentRelay.Protocol`（net10.0）与 `relay handoff verify/lint`；修正 UTC、路径、错误码、Context 示例和 reviewer-final 映射；16 个 conformance case 与 L2–L5 测试接入。
- **可靠性**：回执在 Relay 关闭期间写入后，重开只推进一次；截止后迟到回执会记录，但不会自动投下一轮，需用户确认“允许自动发送”。
- **改名**：窗口、托盘、通知、安装器显示名、README 与文档标题改为 TaskBaton（原 Agent Relay）；程序集、命名空间、项目目录、`RELAY_HOME`、安装器 AppId 和旧数据字段保持不变。
- **连接预设**：提供 Codex ACP、Claude ACP、Claude Code CLI、Gemini CLI、OpenCode 的可审查预设和 doctor；预设不等于已验证接通。

## 安装

Windows x64 安装包：

```
AgentRelay-v0.5.0-windows-x64-setup.exe
```

从发布页下载，或使用工作区中的本地安装包。升级前先从托盘退出 TaskBaton；安装器使用同一 AppId 和同一目录覆盖安装，数据在“中转站”目录中，不随安装目录删除。

## 已知边界

- macOS 没有桌面包；CLI/MCP 有 Windows/Linux CI 覆盖。
- 正式整夜（≥8 小时）托盘自动消费、真实 Claude/Codex 模型交接、真实宿主规则部署、六语语言自然度、DSH 共享图片清理仍需人工补测。
- 测试安装器已隔离 AppId、安装目录、位置文件和输出包名；隔离安装/升级/卸载的实际验收以本轮构建产物为准。
- 并行/条件流转保留但不在本版主推。
