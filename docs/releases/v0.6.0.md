# TaskBaton 0.6.0 — 2026-11-18

0.6.0 完成内部标识、安装目录、数据目录和客户端的 TaskBaton 改名，并为旧版 0.5.0/Agent Relay 保留兼容与迁移路径。

## 主要变化

- 项目、命名空间、程序集改为 `TaskBaton.*`；CLI 主命令 `taskbaton`（别名 `tb`），MCP 为 `taskbaton-mcp`。
- 安装目录改为 `%LOCALAPPDATA%\Programs\TaskBaton`；默认数据目录改为 `%LOCALAPPDATA%\TaskBaton`。
- 数据文件：`taskbaton.db`、`taskbaton.location.json`；演示目录 `TaskBaton.Demos`，规则目录 `TaskBaton.Guidance`。
- 环境变量：首选 `TASKBATON_HOME`，兼容 `RELAY_HOME`；调用上下文同时发出/读取 `TASKBATON_CALLER_*` 与 `AGENT_RELAY_CALLER_*`。
- 安装器使用新 AppId，并在安装前检测旧 AppId/旧安装目录；旧版桌面或通知仍在运行时安全中止，退出后自动静默卸载旧版并保留数据。
- 旧数据迁移：首次解析到旧默认数据目录时，复制到新目录，校验数据库 `quick_check` 与 Agent/任务计数，保留旧目录用于回滚；失败则回退旧目录，不删除用户数据。
- 兼容垫片：安装包同时提供 `relay.exe`、`relay-mcp.exe`、`tb.exe`，旧脚本/旧配置仍可调用。
- 保留外部契约：`relay_version`、`relay_plan`、`.relay/turn-*`、`{relay_home}`、MCP 工具名 `relay_task_*`、规则标记 `<!-- agent-relay:... -->` 等不变，旧任务与旧指令文件继续工作。

## 验证

- Core 489、Protocol 54、Desktop 445 检查通过。
- 新增 6 项迁移回归：旧默认目录复制/校验、旧目录保留、旧 guidance 标记、旧 `relay.db`、旧/新 location、`RELAY_HOME`/`TASKBATON_HOME`/`--home` 优先级、调用上下文前缀回退。
- 隔离测试安装器使用独立 AppId/安装目录/位置文件，安装/卸载通过。
- 旧 AppId 自动卸载流程已编译检查；正式覆盖升级在发布前单独执行。

## 安装

Windows x64 安装包：`TaskBaton-v0.6.0-windows-x64-setup.exe`

从发布页下载或使用工作区本地安装包。升级前先从托盘退出旧版 TaskBaton/Agent Relay；安装器会检测旧版并保留数据。

## 已知边界

- 真实模型交接、整夜值守、六语人工检查、DSH 共享图片清理仍需人工补测。
- `relay.exe`/`relay-mcp.exe` 是兼容垫片，后续大版本再评估移除。
- `.relay` 控制目录、协议 JSON 字段与旧规则标记本版保持不变，避免破坏已有任务/指令文件。
- 桥接依赖自带（Node/ACP 包内嵌）放到下一轮。
