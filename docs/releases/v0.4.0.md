# Agent Relay 0.4.0

## 简体中文

- **中断恢复**。投递结果未确认时，可继续等待、查看已知的目标会话和立即检查回执。确认未送达后可为当前轮次授权一次手动重发。有效的迟到回执仍会处理，并撤销该轮次的重发授权。
- **接力模板**。支持单次交接、双向接力、执行 → 测试 → 修改，以及带复测的五步接力。可调整起始 Agent 和每步职责，创建前可查看步骤数、交接次数和结束方。接力在修改步骤结束时会提示尚未复测。
- **文件归属与清理**。在设置的「中转站存储」中可查看文件归属和任务引用，预览并确认要清理的过期中转文件。仍被任务引用的文件、用户源文件、交付物和任务控制文件受保护。已删除的内部 CLI 草稿不再作为用户源文件出现在清单里。
- **达标迭代**。选择验收模式后再设置验收者、标准和轮数。验收通过即结束，达到上限仍未达标时暂停并显示待解决事项。独立验收使用任务专用会话，后续复验沿用该会话。
- **桥接与回执**。桥接提前返回会话 ID 时及时记录；各轮次分别保存回执和上下文。看板区分投递、Agent 处理和宿主轮次结束。DSH 探针清理按已确认的会话和附件归属处理。

升级前请从托盘退出 Agent Relay，备份中转站及位置记录，再覆盖安装到原目录。

## English

- **Interrupted handoffs**. When delivery is unconfirmed, keep waiting, inspect the known conversation, or check for receipts. Confirm non-delivery to authorize one manual resend. A valid late receipt still advances the task and clears that authorization.
- **Relay templates**. Start from a single handoff, a two-step relay, a work–test–revise relay, or a five-step relay with retesting. Edit the starting Agent and each step's duty, then preview the steps, handoff count and final Agent. A relay that ends on revision shows that the change still needs retesting.
- **Relay file ownership and cleanup**. See file ownership and task references in Settings, then preview and confirm cleanup of expired Relay-managed files. Active references, user sources, deliverables and task control files are protected. Removed internal CLI drafts are hidden from the inventory.
- **Acceptance loops**. Choose the reviewer, criteria and review limit in acceptance mode. Approval completes the task. Unresolved work at the limit pauses for a decision. Independent acceptance uses a dedicated conversation across reviews.
- **Bridge and receipt handling**. Relay saves conversation IDs as soon as a bridge reports them and stores receipt and context files per turn. The board reports delivery, Agent progress and host completion separately. DSH probe cleanup follows verified session and attachment ownership.

Before upgrading, exit Agent Relay from the tray, back up the relay folder and location record, then install into the existing directory.
