# Agent Relay 0.2.0

## 简体中文

- 中转站迁移支持排队：等待活动交接与投递结束后再切换。迁移完成会提示旧目录和具体清理时间；24 小时后在 Relay 运行时或下次启动时清理未改动的迁移文件，新增或修改的文件会保留并列出。新生成提示词、任务上下文和受控路径随新中转站更新。
- 提示音更换为水滴声、钢琴轻音和温馨和弦，保留错误提示音与静音；已有声音偏好对应到新音效。
- Agent 自配置增加节点 ID 提醒：每新增一个节点都要重新复制提示词，不要给两个 Agent 共用同一份。
- 复制桥接诊断提示词仅在实际故障时显示；测试桥接与重新检测并恢复桥接移入 Agent 桥接卡片。
- 新会话默认模型卡片支持展开、收起和重新展开。
- 探针测试支持清理有归属证据的会话与产物，保留已验证的桥接能力，并保护绑定实际任务的会话。Zcode 同步侧栏索引并报告备份；Hermes 使用宿主删除命令并检查关联会话与残留文件。
- Zcode 探针旁增加问号，说明宿主索引或缓存可能延迟显示会话，建议切换会话、等待约 11 分钟或保存后重启，不必为刷新列表重复运行收费探针。

DSH、WorkBuddy 等缺少可靠删除接口的宿主，以及没有归属证据的旧探针，会保留并报告，不能保证自动删除。中转站清理不依赖后台服务；迁移前已复制到外部的短提示词需要重新复制。

本版通过 362 项核心回归与 331 项 Windows 桌面检查。安装、覆盖升级和卸载使用独立产品标识及假数据验收。升级前请退出托盘中的 Agent Relay、备份整个中转站，再使用相同安装目录覆盖安装。

## English

- Relay folder moves can wait for active handoffs and deliveries to finish. Once moved, Relay shows the old folder and its cleanup time. After 24 hours, while running or at the next start, it removes unchanged migrated files and reports any new or modified files it keeps. Newly generated prompts, task context and managed paths follow the new relay folder.
- Replaces the notification cues with Water drop, Soft piano and Warm chord, retaining the error sound and silence. Saved sound choices map to the new cues.
- Adds setup help explaining that every new Agent node needs a freshly copied prompt with its own ID.
- Shows bridge diagnostic prompts only for actual failures, and moves testing and recovery into the Agent bridge card.
- Allows the new-conversation model card to expand, collapse and reopen.
- Adds cleanup for recorded probe sessions and files while retaining verified bridge capabilities and protecting sessions bound to real tasks. Zcode cleanup synchronizes sidebar indexes and reports backups; Hermes uses its session deletion command with checks for related sessions and leftover files.
- Adds a help icon beside Zcode probes explaining delayed session visibility from the host index or cache. Switch conversations, wait about 11 minutes, or save and restart the host instead of repeating a paid probe to refresh the view.

Hosts without a reliable deletion interface, including DSH and WorkBuddy, and older probes without ownership evidence are retained and reported. Folder cleanup does not require a background service. Short prompts copied before a move need to be copied again.

This release passes 362 core tests and 331 Windows desktop checks. Installation, upgrade and uninstall acceptance uses a separate product identity and fixture data. Before upgrading, exit Agent Relay from the tray, back up the entire relay folder, and install over the existing installation in the same directory.
