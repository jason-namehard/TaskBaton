# Agent Relay 0.3.0

## 简体中文

- 新建自动任务支持图片和文字一同输入。可直接粘贴剪贴板中的图片，也可粘贴或拖入图片文件；缩略图显示在文字上方。移到图片上或用键盘聚焦后可删除单张图片，不影响其它图片和文字。
- 点击缩略图打开大图预览：滚轮围绕鼠标位置缩放，按住鼠标拖动，松开后保留位置。按 Esc 或点击右上角关闭按钮返回原窗口，草稿保留。
- 图片在创建任务时保存为受管快照；任务详情提供图片预览。图片随协作轮次交给后续 Agent，重启或迁移中转站后仍保持引用，并沿用任务产物的过期清理规则。图片丢失或过期时明确报告。
- DSH 桌面桥接与声明支持图片的 ACP 桥接发送原生图片。其它 CLI 通过本地图片路径和读图要求传递，目标 Agent 需要具备读图工具及模型能力。ACP 未声明支持图片时，在创建或载入目标会话前拒绝；DSH 模型不支持图片时报告未发送。
- PDF、视频、音频及其它非图片附件输入会弹出提示，请将完整文件路径粘贴到工作要求中；已有文字和图片不会被清空。普通文本粘贴不受影响。

核心回归覆盖 390 项测试，Windows 桌面检查 370 项。安装、覆盖升级和卸载使用独立产品标识及假数据验收；本次没有对真实宿主发起收费图片任务。升级前请退出托盘中的 Agent Relay，备份整个中转站及位置记录，然后在原目录覆盖安装。

## English

- New automatic tasks accept images and text together. Paste images from the clipboard, or paste or drop image files. Thumbnails appear above the text. Hover over or focus an image to remove it without changing the rest of the draft.
- Click a thumbnail to preview it. Use the mouse wheel to zoom around the pointer and drag to pan; releasing the mouse keeps the position. Press Esc or the top-right close button to return with the draft intact.
- Task creation saves managed image snapshots. Task details retain image previews. Images remain available across collaboration turns, restarts and relay-folder moves, and follow the task artifact retention policy. Missing or expired images produce an explicit error.
- DSH desktop and image-capable ACP bridges send native image content. Other CLI bridges send local image paths and instructions to inspect them; the recipient needs image-reading tools and a capable model. ACP agents without declared image support are rejected before creating or loading a target session. DSH model capability errors are reported as unsent requests.
- Pasting or dropping PDFs, videos, audio or other non-image attachments shows a notice asking for the full file path in the work request. Existing text and images remain intact. Ordinary text paste continues to work.

Core regression covers 390 tests and Windows desktop checks cover 370 assertions. Installer, upgrade and uninstall acceptance uses a separate product identity and fixture data; no paid image tasks were sent to real hosts. Before upgrading, exit Agent Relay from the tray, back up the entire relay folder and its location record, and install into the existing directory.
